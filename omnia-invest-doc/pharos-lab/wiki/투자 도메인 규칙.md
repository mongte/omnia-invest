# 투자 도메인 규칙

> pharos-lab은 **투자 참고 정보 플랫폼**이다. 특정 종목 매수·매도를 권유하지 않는다. UI·카피·시그널 라벨 모두에 적용.

## 금지 표현 → 대체

| 금지 | 대체 |
|------|------|
| 매수 유리 | 긍정적 신호 |
| 매수 추천 | 참고 지표 |
| 매수 권유 | 중립 표현 |
| 투자 추천 | 데이터 기반 분석 |
| 종목 추천 랭킹 / 퀀트 랭킹 등 | **데일리 추천 랭킹** (이 명칭만) |

코드·UI 텍스트 모두 포함. 리뷰·QA 시 금지 표현 검색 권장.

## 면책 문구 (필수 유지)

```
본 서비스는 투자 참고 정보를 제공하며, 특정 종목의 매수·매도를 권유하지 않습니다.
투자 판단과 그에 따른 책임은 이용자 본인에게 있습니다.
```

### 배치 위치
- 대시보드 하단 — `widgets/dashboard/` 섹션
- 랜딩 footer — `widgets/landing/landing-footer.tsx`
- 랭킹 tooltip — 랭킹 리스트 컴포넌트

## 퀀트 점수와 랭킹

- `stocks.quant_score`: 0–100. **데일리 추천 랭킹** 정렬 기준
- 시그널 구간 라벨도 투자 권유 톤을 피하고 중립 표현을 우선

## 가상 투자 흐름

```
virtual_orders 생성
  → virtual_positions 갱신
  → virtual_equity 일일 자산 기록
```

자동 매매 규칙: `auto_trade_rules` (rule_type, trigger_price/signal, status).

## Auth Gate

보호 기능(가상 투자, 보유 종목, 자동 매매 규칙 등)은 `features/auth/lib/use-auth-gate.ts` 패턴 사용. 미로그인 시 로그인 모달 유도.

## 에이전트 적용

구현·리뷰·QA 시 앱 스킬 `pharos-domain`을 로드한다. 아키텍처는 [[FSD 앱 구조]], 데이터 원천은 [[데이터 파이프라인과 Supabase]], 제품 맥락은 [[제품 개요와 스택]].
