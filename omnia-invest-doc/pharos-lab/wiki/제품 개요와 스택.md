# 제품 개요와 스택

> 퀀트 기반 투자 분석 플랫폼. 코스피 관찰 유니버스 데이터를 대시보드로 시각화하고, 가상 투자·보유 종목 관리 UI를 제공한다.

## 한 줄 정의

**pharos-lab** (`apps/pharos-lab`)은 Supabase에 적재된 종목·공시·점수 데이터를 조회하는 Next.js 앱이다. 투자 권유 플랫폼이 아니라 **투자 참고 정보** 제공이 목적이다. 도메인 규칙은 [[투자 도메인 규칙]] 참고.

## 기술 스택

| 레이어 | 기술 |
|--------|------|
| 프레임워크 | Next.js 16 (App Router) + React 19 |
| 언어 | TypeScript strict (`any` 금지) |
| 스타일 | Tailwind CSS 4 + shadcn/ui (Radix) |
| 차트 | lightweight-charts (캔들), Recharts (레이더/라인/에어리어) |
| 서버 상태 | TanStack Query |
| 클라이언트 상태 | Zustand (auth 등) |
| DB | Supabase (PostgreSQL) + `@supabase/ssr` |
| PWA | Serwist |
| 배포 | Vercel |

## 주요 라우트

| 경로 | 역할 |
|------|------|
| `/` | 랜딩 — 서비스 소개·기능 미리보기 |
| `/dashboard` | 종목 대시보드 — 차트, 점수 레이더, 데일리 추천 랭킹, 공시, LLM 요약 |
| `/virtual-trading` | 가상 투자 — 계좌, 포지션, 주문, AI 신호, 자동매매 규칙 |
| `/my-stocks` | 내 주식 관리 — 보유 종목·포트폴리오 요약 (auth 필요) |
| `/api/stocks`, `/api/stocks/[id]`, `/api/stocks/[id]/llm-summaries` | 종목 API Route Handlers |
| `/auth/callback` | Supabase OAuth 콜백 |

## 현재 상태 (조사 시점)

- trading 스키마 수집 + public 동기화 완료 (stocks·disclosures 등)
- 대시보드·가상투자·내 주식 UI/API 파일 존재
- 일부 뷰/위젯이 아직 `shared/lib/mock-data.ts`를 참조할 수 있음 → 실 API 교체 대상
- 3-Layer 스코어링은 분석 스크립트·스케줄과 연동 ([[데이터 파이프라인과 Supabase]])
